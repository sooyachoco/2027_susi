# 입시결과 데이터 정책

## 원칙

- 2027 전형정보와 2026 입시결과를 분리한다.
- 숫자는 대학 공식 결과 또는 어디가 원문 표를 확인한 경우에만 `verified`로 승격한다.
- 검색 결과의 요약 숫자만으로 모집인원/컷/충원율을 추정하지 않는다.
- 검증 전 레코드는 `source-linked` 상태로 두고 추천엔진의 역사적 컷 계산에는 사용하지 않는다.
- 모든 결과에는 `source`와 `verifiedAt`을 남긴다.

## 현재 단계

2027 어디가 대학정보 페이지에서 2026 전형 결과 영역이 공개되고 있음을 확인했다. 어디가의 2027 대학별 점수산출 서비스는 학생부·수능 성적을 대학별 산출식으로 계산하고 전년도 입시결과와 비교하는 용도이므로, 이후 숫자 검증 단계에서 동일한 전형 단위로 연결한다.

## 다음 데이터 입력 단위

`대학 → 전형 → 모집단위 → 모집인원 → 경쟁률 → 충원율 → 70%/최종등록자 등 공개 지표 → 출처`
