# 입시결과 데이터 정책

## 원칙

- 2027 전형정보와 2026 입시결과를 분리한다.
- 숫자는 대학 공식 결과 또는 어디가 원문 표를 확인한 경우에만 `verified`로 승격한다.
- 검색 결과의 요약 숫자만으로 모집인원/컷/충원율을 추정하지 않는다.
- 검증 전 레코드는 `source-linked` 상태로 두고 추천엔진의 역사적 컷 계산에는 사용하지 않는다.
- 모든 결과에는 `source`와 `verifiedAt`을 남긴다.
- 2027 전형 메타데이터가 확인됐더라도 2026 입결 숫자가 없는 전형은 합격선/합격확률을 만들어내지 않는다.

## 2026-08-25 현재

`lib/data/verified2027.ts`에 서울·경기·인천 11개 대학의 2027학년도 전형 메타데이터를 1차 반영했다. 현재 포함 대학은 고려대, 연세대, 이화여대, 동국대, 한국외대, 숭실대, 단국대, 아주대, 명지대, 인하대, 인천대다.

2027학년도 어디가 대학정보 페이지에서 전형별 주요사항과 모집인원 등 공개값을 확인한 레코드는 `adiga` 출처와 수집일을 남겼다. 예를 들어 이화여대 미래인재 서류형 909명/면접형 209명, 인하대 인하미래인재 면접형 939명/서류형 261명, 인천대 교과성적우수자 456명 등은 해당 어디가 원문에서 확인한 값이다.

어디가는 2027학년도 수시 대학별 점수산출 서비스를 2026-07-21 오픈했고, 대학별 산출식으로 학생부·수능 성적을 계산해 전년도 입시결과와 비교할 수 있다고 안내한다. 따라서 다음 단계에서는 동일한 `대학 → 전형 → 모집단위` 단위로 2026 결과표를 연결한다.

## 현재 데이터 상태

- `verified2027.ts`: 2027 전형 메타데이터 — **사용 가능**
- 2026 경쟁률/충원율/70%컷/최종등록자 등 — **추가 검증 중**
- 검증 전 숫자 — 추천엔진에서 **사용 금지**
- 진학사 전략자료 — 전략 해석 레이어로 별도 연결

## 다음 데이터 입력 단위

`대학 → 전형 → 모집단위 → 모집인원 → 경쟁률 → 충원율 → 70%/최종등록자 등 공개 지표 → 출처`
